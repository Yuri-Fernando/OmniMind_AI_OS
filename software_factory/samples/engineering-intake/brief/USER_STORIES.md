# User stories

- US-1 Como engenheiro, quero submeter um desenho e receber um `job_id` imediatamente,
  para não esperar o processamento.
- US-2 Como engenheiro, quero consultar o status do job e o histórico de eventos.
- US-3 Como integrador, quero reenviar uma requisição com a mesma chave de idempotência
  sem criar jobs duplicados, e ser avisado se a chave foi reutilizada com outro conteúdo.
- US-4 Como responsável por segurança, quero que nenhum nome de arquivo consiga escrever
  fora do diretório de armazenamento.
